# Задание

Създайте външен CSS файл и стилизирайте предоставената HTML5 страница така, че тя да изглежда като завършена част от реален уебсайт.

# Изисквания

Вашето решение трябва да отговаря на следните условия:

1. Да използва само външен CSS файл.
2. Да не използва:
   - inline styles;
   - JavaScript;
   - CSS flexbox;
   - CSS grid.
3. Да има ясно разграничени и стилизирани основни части на страницата:
   - `header`
   - `nav`
   - `main`
   - `section` / `article`
   - `aside`
   - `footer`
4. Да съдържа единна визуална тема, включваща:
   - един базов/фонов цвят;
   - един основен цвят, който да се използва последователно за заглавия, бутони, рамки или други акценти.
5. Да има стилизирани:
   - заглавия;
   - параграфи;
   - списъци;
   - линкове;
   - повтарящи се блокове от съдържание.
6. Да се използват подходящо основни CSS свойства като:
   - `color`
   - `background-color`
   - `margin`
   - `padding`
   - `border`
   - `width`
   - `text-align`
   - `font-size`
   - `display`
7. Страницата трябва да изглежда подредена, четима и визуално последователна.

# Подсказки

1. Започнете с най-общите елементи: `body`, `header`, `main`, `footer`.
2. Първо изберете двата основни цвята, а след това стилизирайте отделните части.
3. Използвайте `margin` и `padding`, за да направите страницата по-подредена.
4. Ако няколко елемента трябва да изглеждат еднакво, потърсете начин да използвате общо правило.
5. Работете постепенно: първо общ вид, после детайли.
