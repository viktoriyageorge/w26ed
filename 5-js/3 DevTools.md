## 🛠 Developer Tools (DevTools)

Developer Tools представляват вградени инструменти в браузъра за разработка, анализ и тестване на уеб приложения.

Позволяват директна работа със структурата, стила и поведението на страницата.

---

## 🚪 Достъп

- клавиш F12
- десен бутон → Inspect

---

## 🧩 Основни панели

---

### 🟢 Elements

Панел за визуализация на HTML структурата (DOM).

Функционалности:
- преглед на HTML елементи
- редакция на съдържание
- добавяне и премахване на елементи

Пример:

Редакция на текст:

```html
<h1>Заглавие</h1>
```

Промяна директно в Elements → текстът се обновява веднага в страницата.

---

### 🎨 Styles

Панел за CSS правила, приложени към избрания елемент.

Функционалности:
- преглед на активни стилове
- временно изключване на стилове
- добавяне на нови CSS правила

Пример:

```css
color: red;
```

Резултат: текстът се оцветява в червено в реално време.

---

### ⚡ Console

Панел за изпълнение на JavaScript и преглед на съобщения.

Функционалности:
- изпълнение на JavaScript код
- извеждане на информация чрез `console.log`
- преглед на грешки

Примери:

Смяна на текст:

```javascript
document.querySelector("h1").textContent = "Нов текст";
```

Смяна на фон:

```javascript
document.body.style.backgroundColor = "lightblue";
```

Скриване на елемент:

```javascript
document.querySelector("nav").style.display = "none";
```

Показване на елемент:

```javascript
document.querySelector("nav").style.display = "block";
```

---

### 🌐 Network

Панел за наблюдение на заявки към сървъра.

Функционалности:
- списък със заредени ресурси: HTML, CSS, JS, изображения
- време за зареждане
- статус на заявките

Пример:

Презареждане на страницата → визуализиране на всички HTTP заявки.

---

## 🧠 DOM (Document Object Model)

DOM представлява вътрешното представяне на HTML документа като дървовидна структура.

Всеки HTML елемент се превръща в обект, достъпен чрез JavaScript.

Пример:

```html
<h1>Заглавие</h1>
```

Достъп чрез JavaScript:

```javascript
document.querySelector("h1")
```

Позволява:
- четене на съдържание
- промяна на текст
- промяна на стилове
- добавяне на елементи

---

## 🎯 Обобщение

DevTools предоставят възможност за:

- инспекция на HTML структура: Elements
- промяна и тестване на CSS: Styles
- изпълнение на JavaScript: Console
- анализ на заявки: Network

---

## 💡 Важно

Промените, направени чрез DevTools:
- са временни
- изчезват при презареждане на страницата

```javascript

```

Резултат: моментална визуална промяна на страницата.
