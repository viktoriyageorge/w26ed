## ⚡ JavaScript – интуитивно обяснение

**JavaScript** е скриптов език, който се изпълнява директно от браузъра или друга runtime среда.

Основна роля:
добавяне на поведение към уеб страниците

---

## 🧭 Какво прави JavaScript

HTML създава структура  
CSS създава визия  

JavaScript:
- реагира на действия (click, input)
- променя съдържание
- добавя нови елементи
- валидира данни

---

## 🧠 Какво е „скриптов език“

Скриптов език е език, при който:

- кодът не се компилира предварително до самостоятелен файл
- изпълнението се извършва от друга програма (runtime)
- кодът се изпълнява директно

Runtime среда = система, която чете и изпълнява кода  

Примери:
- браузър (Chrome, Firefox)
- Node.js

---

## ⚙️ Как се изпълнява JavaScript в браузъра

1. Зареждане на HTML
2. Откриване на <script> елемент
3. Зареждане на JavaScript код
4. Изпращане към JavaScript engine (напр. V8)
5. Изпълнение на кода

---

## 🔍 Какво прави engine-ът

- parsing (прочитане на кода)
- интерпретация
- JIT компилация (при нужда)
- изпълнение

---

## 🔄 Разлика спрямо други езици

C++:
- код → компилация → .exe
- самостоятелна програма

Java:
- код → bytecode → JVM
- изпълнение чрез виртуална машина

JavaScript:
- код → директно към браузъра
- изпълнение веднага

---

## 🧩 Пример

HTML:

<button>Натисни</button>

JavaScript:

document.querySelector("button").addEventListener("click", function() {
    alert("Здравей!");
});

---

## 🧪 Друг пример

document.body.style.backgroundColor = "lightblue";

---

## ⚡ Кога се изпълнява JavaScript

- при зареждане на страницата
- при събития:
  - click
  - input
  - submit
  - scroll

---

## 🧠 Основна идея

JavaScript работи със DOM (HTML структурата в браузъра)

Позволява:
- четене на елементи
- промяна на текст
- промяна на стил
- добавяне/премахване на елементи

---

## 🚀 Модерна реализация

- JIT (Just-In-Time compilation)
- оптимизации по време на изпълнение

---

## 🎯 Обобщение

JavaScript е:

- скриптов език
- изпълняван от runtime среда
- директно интегриран в браузъра
- използван за създаване на интерактивност

---

## 💡 Най-важното

HTML = структура  
CSS = стил  
JavaScript = поведение

JavaScript прави страницата „жива“
