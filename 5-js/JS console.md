## JavaScript в Console (браузър)

Браузърът позволява директно изпълнение на JavaScript чрез Developer Tools.

### Стъпки

1. Отвори произволна уеб страница
2. Натисни:
   - F12 или
   - Right click → Inspect
3. Избери таб **Console**
4. Напиши:

   alert("Hello, JavaScript!");

5. Натисни Enter
