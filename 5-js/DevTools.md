## Developer Tools (DevTools)

Developer Tools са вградени инструменти в браузъра за разработка и анализ на уеб приложения.

### Достъп
- F12
- Right click → Inspect

### Основни панели

- **Elements**
  - HTML структура (DOM)
  - Преглед и редакция на елементи

- **Styles**
  - CSS правила
  - Промяна на стилове в реално време

- **Console**
  - Изпълнение на JavaScript
  - Преглед на грешки и логове

- **Network**
  - HTTP заявки (клиент ↔ сървър)
  - Зареждане на ресурси

### Обобщение

DevTools позволяват:
- инспекция на код
- тестване
- дебъгване

👉 Основен инструмент за всеки уеб разработчик
