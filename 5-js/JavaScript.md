## JavaScript – интуитивно обяснение

**JavaScript** е скриптов език, който се изпълнява директно от браузъра или друга runtime среда.

---

## Какво е „скриптов език“

Скриптов език е език, при който:
- кодът не се компилира предварително до самостоятелен изпълним файл
- изпълнението се извършва от друга програма (runtime)
- кодът се обработва и изпълнява по време на изпълнение (runtime)

👉 Runtime среда = система, която чете и изпълнява кода  
(напр. браузър, Node.js)

---

## Разлика спрямо компилируеми езици

- **C++**
  - код → компилация → `.exe`
  - изпълнение като самостоятелна програма

- **Java**
  - код → компилация → bytecode → JVM
  - JVM изпълнява кода

- **JavaScript**
  - код → директно към runtime среда
  - няма ръчна компилация от страна на потребителя

---

## Изпълнение в браузър

1. Браузърът зарежда HTML
2. Открива `<script>` елемент
3. Зарежда JavaScript код
4. Предава кода на JavaScript engine (напр. V8)
5. Engine-ът:
   - анализира (parsing)
   - преобразува във вътрешно представяне
   - изпълнява кода

---

## Характеристики

- изпълнение при зареждане или при събитие (click, input)
- директна работа с HTML (DOM)
- динамична промяна на съдържание

---

## Модерна реализация

- използва се JIT (Just-In-Time compilation)
- част от кода се компилира по време на изпълнение
- подобрява производителността

---

## Обобщение

JavaScript е:
- скриптов език
- изпълняван от runtime среда
- използван за добавяне на поведение към уеб страници

👉 ключова идея:
HTML = структура  
CSS = стил  
JavaScript = поведение
