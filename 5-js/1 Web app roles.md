## 🌐 Основни роли в уеб приложение

Уеб приложението се състои от три основни части:

- Frontend (клиентска част – браузър)
- Backend (сървърна част)
- Database (база данни)

---

## 🖥 Frontend (в браузъра)

Frontend е всичко, което потребителят вижда и с което взаимодейства.

Състои се от:

- HTML → структура (какво има на страницата)
- CSS → стил (как изглежда)
- JavaScript → поведение (как реагира)

Пример:

HTML:

```html
<button>Натисни</button>
```

CSS:

```css
button {
  background-color: blue;
  color: white;
}
```

JavaScript:

```javascript
document.querySelector("button").addEventListener("click", function() {
  alert("Бутонът беше натиснат");

  // Тук може да се добави логика:
  // изпращане на данни към сървъра
  // например чрез fetch / AJAX
});
```

Резултат: бутонът изглежда добре и реагира при натискане.

JavaScript може да съдържа логика, която:

- обработва данни в браузъра
- реагира на действия на потребителя
- изпраща заявка към сървъра

---

## ⚙️ Backend (на сървъра)

Backend обработва заявките и бизнес логиката на приложението.

Примерни задачи:

- обработка на форми
- валидиране на данни
- комуникация с база данни
- връщане на резултат към клиента

Пример:

- потребител изпраща форма
- PHP обработва данните
- PHP извиква база данни
- сървърът връща резултат към браузъра

---

## 🗄 Database (база данни)

Базата данни съхранява информацията на приложението.

Използва се чрез SQL (Structured Query Language).

Примерни операции:

- запис на данни (INSERT)
- извличане на данни (SELECT)
- обновяване на данни (UPDATE)
- изтриване на данни (DELETE)

Примери:

- запис на нов потребител
- извличане на списък с курсове
- проверка на логин данни

Важно:

Браузърът не комуникира директно с базата данни.  
Обикновено комуникацията минава през backend.

---

## 🔄 Как работи процесът

1. Потребител отваря страница в браузър.
2. Браузърът изпраща заявка към сървъра (HTTP request).
3. Backend (например PHP) обработва заявката.
4. Backend комуникира с база данни чрез SQL.
5. Базата данни връща резултат.
6. Backend подготвя отговор.
7. Сървърът връща HTML, CSS, JavaScript или данни.
8. Браузърът визуализира страницата.
9. JavaScript добавя интерактивност.

---

## 🔁 Допълнителна комуникация

JavaScript може да изпраща нови заявки без презареждане на страницата.

Това често се нарича:

- AJAX
- fetch request

Примерен процес:

1. Натискане на бутон.
2. JavaScript изпраща заявка към сървъра.
3. Backend обработва заявката.
4. Backend взима данни от база.
5. Сървърът връща резултат.
6. JavaScript обновява част от страницата.

---

## 🧠 Основна идея

Frontend:

- визуализация
- взаимодействие с потребителя
- поведение в браузъра

Backend:

- обработка на логика
- валидиране
- комуникация със системи

Database:

- съхранение на данни
- извличане на данни

---

## 🎯 Обобщение

Frontend → това, което потребителят вижда  
Backend → това, което обработва логиката  
Database → това, което съхранява данните  

Трите части работят заедно чрез заявки и отговори.

JavaScript е връзката между потребителя и динамичното поведение на страницата.
