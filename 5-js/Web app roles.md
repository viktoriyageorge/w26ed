## 🌐 Основни роли в уеб приложение

Уеб приложението се състои от две основни части:

- Frontend (клиентска част – браузър)
- Backend (сървърна част)

---

## 🖥 Frontend (в браузъра)

Frontend е всичко, което потребителят вижда и с което взаимодейства.

Състои се от:

- HTML → структура (какво има на страницата)
- CSS → стил (как изглежда)
- JavaScript → поведение (как реагира)

Пример:

HTML:
```html
<button>Натисни</button>
```

CSS:
```css
button {
  background-color: blue;
  color: white;
}
```

JavaScript:
```javascript
document.querySelector("button").addEventListener("click", function() {
  alert("Бутонът беше натиснат");
});
```

Резултат: бутонът изглежда добре и реагира при натискане

---

## ⚙️ Backend (на сървъра)

Backend обработва данните и логиката на приложението.

Примерни задачи:
- обработка на форми
- работа с база данни
- съхраняване и извличане на информация
- обработка на заявки от клиента

Пример:

- потребител изпраща форма
- PHP обработва данните
- запис в база данни
- връщане на резултат към браузъра

---

## 🔄 Как работи процесът

1. Потребител отваря страница в браузър  
2. Браузърът изпраща заявка към сървъра (HTTP request)  
3. Backend (PHP) обработва заявката  
4. Сървърът връща отговор (HTML, CSS, JS)  
5. Браузърът визуализира страницата  
6. JavaScript добавя интерактивност  

---

## 🔁 Допълнителна комуникация

JavaScript може да изпраща нови заявки без презареждане на страницата (AJAX).

Пример:
- натискане на бутон
- изпращане на заявка към сървъра
- получаване на данни
- обновяване на част от страницата

---

## 🧠 Основна идея

Frontend:
- визуализация
- взаимодействие с потребителя

Backend:
- обработка на данни
- бизнес логика

---

## 🎯 Обобщение

Frontend → това, което потребителят вижда  
Backend → това, което обработва данните  

Двете части работят заедно чрез заявки и отговори  

JavaScript е връзката между потребителя и динамичното поведение на страницата
