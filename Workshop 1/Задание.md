# Задание: Надграждане на CampusHub

## index.html
- Направете „Предстоящи събития“ като картички
- Добавете още едно събитие
- Добавете малък етикет: „Ново“ / „Важно“

## courses.html
Изберете едно:
- курсовете да станат картички;
- преподавателите да станат таблица;
- програмата да стане списък/картички

+ добавете поне още един нов елемент

## contact.html
- Добавете поне 2 нови полета във формата
- Добавете малък информационен блок
- Подредете формата със CSS

## CSS
- хоризонтално меню
- цветове и spacing
- използвайте float или position поне веднъж
