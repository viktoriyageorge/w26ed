Контекст

Котвичките (anchor links) ни позволяват да скачаме към секции в дълъг документ.

Пример: URL-ът добавя #xhtml когато кликнем върху XHTML секцията.

XHTML — строг синтаксис

  • Таговете трябва да са XML-валидни.
  • Атрибутите обикновено се пишат със стойност.
  • Self-closing често изглежда като <input />.

HTML5 — по-гъвкав

  • Булеви атрибути: required може без стойност.
  • Минимален doctype: <!DOCTYPE html>.

Project mindset

Първо подреждаме структурата, после добавяме feature-и — иначе трупаме technical debt.

  • дублиране
  • загуба на контекст
  • непоследователни id/name

Форма → PHP

Формата не изпраща HTML. Тя изпраща HTTP request с двойки name=value.

<form method="post" action="add-user.php">
  <input name="username">
</form>
<?php
echo "Hello " . htmlentities($_POST["username"]);
?>

Technical debt

Без templates/components често копираме еднакви части между страници. Това е пример за early technical debt.
